
# CodeAlpha Task 3 - Data Visualization

## Project Overview
This project focuses on Data Visualization using Python.

The project analyzes an E-Commerce Books dataset and creates static charts, interactive visualizations, and an interactive dashboard to understand book prices and ratings.

## Project Structure

- data/ - Contains the cleaned dataset.
- outputs/ - Stores generated charts, dashboards, CSV and Excel files.
- outputs/charts/ - Stores static visualization charts.
- reports/ - Contains the final text report.
- main.py - Main Python script.
- requirements.txt - Required Python libraries.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- OpenPyXL

## Features

1. Dataset loading and cleaning.
2. Book price and rating analysis.
3. Statistical summary.
4. Five static visualization charts.
5. Five interactive charts.
6. Interactive dashboard.
7. CSV and Excel reports.
8. Automated text report generation.

## How to Run

### Step 1: Install Dependencies

pip install -r requirements.txt

### Step 2: Add Dataset

Place the cleaned dataset inside the data folder.

Dataset filename:
books_cleaned.csv

### Step 3: Run the Project

python main.py

## Output

The project generates:

- Static charts in outputs/charts/
- Interactive HTML charts in outputs/
- Interactive dashboard in outputs/
- CSV and Excel analysis reports in outputs/
- Text report in reports/

## Conclusion

This project provides meaningful insights into E-Commerce book prices and ratings through static and interactive visualizations.
